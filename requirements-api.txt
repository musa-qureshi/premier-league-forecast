# Minimal dependency set for the DEPLOYED backend (Dockerfile) - not the
# full project. requirements.txt at the repo root covers everything
# needed to reproduce the whole pipeline (ingestion, all four model
# families, tuning, SHAP, notebooks); the live API's actual runtime import
# graph is a small, verified subset of that (confirmed by statically
# walking app.backend.main's imports down through src/ - see the Phase 14
# deployment writeup in README.md). Kept as its own file rather than
# trimmed inline in the Dockerfile so it stays reviewable and testable on
# its own (`pip install -r requirements-api.txt` should be enough to run
# `uvicorn app.backend.main:app` standalone).
#
# Notably absent on purpose: scikit-learn, xgboost, statsmodels,
# matplotlib, seaborn, shap, kaggle. None of them are imported - directly
# or transitively - by anything app/backend/main.py's request handlers
# actually reach at runtime (only DixonColesModel is used for the live
# forecast; the other three model families are backtesting/notebook-only,
# and src/data/ingest.py's Kaggle import is function-local/lazy, never
# triggered by the live openfootball-only fetch path). Together those
# packages account for the large majority of the full requirements.txt
# install - trimming them cut the deployed image from ~2.2GB to a small
# fraction of that and the `pip install` step from over two minutes to a
# few seconds.
